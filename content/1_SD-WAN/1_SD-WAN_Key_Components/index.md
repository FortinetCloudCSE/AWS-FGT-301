## SD-WAN Key Components

### FortiGate (FGT)

- Foundation of the SD-WAN solution
  - Built-in intelligence (no controller needed)
  - NGFW
  - Advanced routing support

### FortiManager (FMG)

- SD-WAN Monitoring, Management, and Templatization
- Can be physical appliance, VM (public/private), Saas (FortiManager Cloud)
- Single management console for all SD-WAN/Branch components (FGT, FSW, FAP, FEXT)
- ZTP
- Does NOT need to be operational to make configuration changes or SD-WAN to function properly
  - Many competitors require their orchestrator/controller etc to be available

{{% notice tip %}}
While you can technically build ADVPN and SDWAN without a FMG, it is recommended to use FMG as this addresses deployments with many Branches, simplifies policy management across a diverse environment of FGTs, provides Zero Touch Provisioning, and many more benefits.
{{% /notice %}}

### FortiAnalyzer (FAZ)

- Log collection
- Event management
- Reporting
- FortiView monitoring and visibility

{{% notice tip %}}
In this workshop we are using a single FMG with FAZ features enabled to lower the cost for running this in AWS. It is best practice to use separate deployment, for FMG and FAZ, and to enable HA or some means of automated recovery.
{{% /notice %}}

## SD-WAN Terminology

- **Hub** – The Data Centre side firewalls.
- **Branch** – The remote office firewalls. Sometimes called the "Edge or Spoke" devices.
- **Carrier** – The ISP/WAN/Underlay connection to the internet.
- **Underlay** – A traditional WAN/ISP/MPLS path. VPNs between sites are built using this link.
- **Overlay** – An encrypted IPSec tunnel between a branch and hub (or other branches).
- **ADVPN** – Auto Discovery VPN tunnels. Dynamic "shortcut" tunnels between spokes in the Hub and Spoke topology.

### Key Components of Topology

- **Branch1/2** are configured with provisioning templates generated by the SD-WAN Overlay Templates (SOT) feature. Each has 2 Underlays terminating VPNs to Hub1/Hub2 across both underlays (6 total overlay tunnels).
- **HUB1** and **HUB2** are HA, each having 1 Underlay. Both are configured with provisioning templates generated by SOT.
- **FMG/FAZ** can be hardware or virtual, hosted on premise or in the Cloud. In this demo the FMG with FAZ features enabled is deployed in the Hub1 VPC.
- **Branch3/4** are model device FGTs used for low touch provisioning demo.
- **Internet** – Actual Internet using the AWS backbone for inter-region communication. WAN Impairment is implemented within the Branch1 VPC in front of the FGT.
